怎么玩

用铅笔画线，按空格或「播放」。蓝线能骑，红线会加速，绿线只是风景。骑得太平或者一头撞上线，他就会从雪橇上摔下去。

B / L / E / H / F铅笔、直线、橡皮、抓手、起点
1 / 2 / 3普通线、加速线、风景线
空格播放或暂停。按住空格再拖动可以平移
Esc停止并回到起点
滚轮缩放。起点工具下改为旋转出发方向
Shift画直线时保持水平或垂直
[ / ]慢放 / 快进
C / G镜头跟随 / 残影
Ctrl+Z / Ctrl+Y撤销 / 重做
